机械动力：蓝图互联网（blueprintnet）
==================================

（本说明为纯文本，可直接粘贴进 MC百科 资料页）

————————————————————————————————

【一句话介绍】

在机械动力（Create）的图纸桌里直接浏览社区蓝图站，选中后下载到 schematics 目录，
还能把 Litematica / WorldEdit 的蓝图转成机械动力能读的结构 nbt，并把大工程切成几块。


————————————————————————————————

【功能概览】

打开图纸桌后，面板右上角上方会多出三个按钮：

　　　┌──────────────[CMS][M][处]┐
　　　│　CMS　creativemechanicserver.com（中文社区蓝图站）
　　　│　M　　mcschematic.top（JSON 接口的蓝图站）
　　　│　处　蓝图处理：对 schematics 目录里已有的文件做转换与分割
　　　└────────────────────────┘

具体能做的事：

１．翻页与搜索
　　两个站点都支持翻页（每页 20 条）、按下载量或时间排序、按关键词搜索。

２．下载前先看清
　　详情页给出封面图、尺寸、应力影响、需要的模组版本、材料用量表，以及作者的注释。

３．一键下载进 schematics 目录
　　文件直接落到机械动力读取的目录，回图纸桌即可选用。
　　litematic 与 schem 格式会在下载完成后自动转换成结构 nbt，原始文件保留，不覆盖。

４．大蓝图切块
　　支持竖直（沿 X）、水平（沿 Y）、网格（在 XZ 平面切成 k×k）三种方式，份数可选。
　　产物写进以源文件命名的子目录，不会和原文件混在一起。

５．1.20.1 版的额外内容
　　图纸桌内的文件选择器可以切换 schematics 下的子文件夹；
　　并内置真 3D 预览（带光影、透明方块、方块实体），可拖拽旋转、滚轮缩放。


————————————————————————————————

【版本要求】

请按你的游戏版本选择对应的 jar：

　　1.21.1 版　blueprintnet-1.21.1-0.1.0.jar
　　　　　Minecraft 1.21.1　＋　NeoForge 21.1.265　＋　Create 6.0.10　＋　Java 21

　　1.20.1 版　blueprintnet-1.20.1-0.1.0.jar
　　　　　Minecraft 1.20.1　＋　Forge 47.4.28　＋　Create 6.0.8　＋　Java 17

必须安装机械动力（Create），本模组没有它无法工作。

本模组是纯客户端模组，服务器不需要安装。1.20.1 版已设置为忽略模组版本差异，
因此装了本模组不会导致你无法进入没有装它的服务器。


————————————————————————————————

【安装方法】

１．装好对应版本的 Minecraft、加载器与机械动力。
２．把对应版本的 jar 放进 .minecraft/mods 目录。
３．启动游戏，进入游戏后放一个图纸桌并打开，即可看到三个入口按钮。

本模组不新增物品或方块，全部功能都在现有界面里。


————————————————————————————————

【使用方法】

入口一（推荐）
　　放置图纸桌并右键打开，三个按钮位于面板右上角上方。
　　点 CMS 浏览中文蓝图站，点 M 浏览另一个蓝图站，点「处」处理本地文件。

入口二（快捷命令）
　　在聊天栏输入 /cms、/mcs、/bptool 可直接打开对应界面。

列表页
　　单击一行选中，再点同一行进入详情；方向键上下移动；回车打开详情；
　　滚轮翻页；搜索框输入关键词后按回车或点「搜索」。

详情页
　　左上为预览框，右上为标题、作者、下载量、尺寸、应力、版本与注释，
　　下方是整幅宽的「文件 / 材料」两个标签页。
　　预览框右下角的小角标可以在三种来源之间切换：
　　　「图」站点封面图（点击可全屏放大，滚轮缩放）
　　　「3D」赛博护目镜的 3D 预览（仅 1.21.1 版，且需安装该模组）
　　　「俯」内置俯视投影，不依赖任何其他模组
　　文件行右侧的「下载」把文件存到 schematics 目录并自动转换格式。

分割页
　　选择竖直、水平或网格方式，再用预设档位或加减号调整份数，
　　预览行会先算出将生成几份、每份多大，确认后才真正写入磁盘。

蓝图处理页
　　列出 schematics 目录下的所有蓝图文件，支持进入子目录（点目录行进入，退格或「..」返回上级），
　　可以对选中的文件转换格式或分割。


————————————————————————————————

【配置文件】

首次启动会生成 config/blueprintnet.properties：

　　site=https://www.creativemechanicserver.com
　　userAgent=（浏览器 UA 字符串）
　　proxy=
　　timeoutSeconds=30
　　requestIntervalMs=300

proxy 填「主机:端口」即可走代理。两个站点都连不上时，先检查这一项。


————————————————————————————————

【已知限制】

１．依赖上表所列的机械动力版本，因为它用到了图纸载入器与界面贴图，
　　机械动力大版本更新后需要重新编译本模组。
２．三个入口按钮只在图纸桌界面出现。
３．1.21.1 版的 3D 预览需要另装 Create Cyber Goggles（赛博护目镜）；
　　没装时该档自动跳过，封面图与俯视预览仍可正常使用。
４．转换只有一个方向：其他格式转成机械动力的结构 nbt。
　　MCEdit 的 schematic（数字 ID 格式）可以列出、可以分割，但不能转换。
５．本模组没有使用 Mixin：按钮由模组自行绘制并自行判定点击，
　　因此只能用鼠标操作，键盘 Tab 键无法选中它们。
